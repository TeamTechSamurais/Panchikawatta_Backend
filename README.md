# Panchikawatta Mobile Application — Backend

Backend services for Panchikawatta, a mobile marketplace application for buying and selling vehicle spare parts and services.

## Tech Stack
- **Runtime:** Node.js
- **Database:** PostgreSQL
- **ORM:** Prisma
- **Services:** Firebase integration

## Key Features
- REST API backend supporting the Panchikawatta mobile app
- Database management for marketplace listings, users, and transactions
- Backend support for real-time chat and profile management features

## Team
Built collaboratively by a 5-member team (TeamTechSamurais) as an academic group project.

## Project Status
Core backend features implemented, including order management and API endpoints supporting the mobile app. Refinements ongoing.
